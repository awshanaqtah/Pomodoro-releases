# Pomodoro — releases

Installers and the update feed for **Pomodoro**, a small nature-themed focus timer for Windows.

- Download the latest installer from [Releases](https://github.com/awshanaqtah/Pomodoro-releases/releases/latest).
- Installed copies check `latest.json` on the latest release and offer updates on their own.
  Every update is signed, and the app refuses anything that isn't.

The source code is private; this repository only holds release files.
